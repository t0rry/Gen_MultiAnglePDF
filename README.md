# マルチアングル画像PDFジェネレータ

CGソフトで作成したモデルを複数の角度から撮影した画像をPDFやPNGに配置するツールです。クライアント提出用の資料を簡単に生成できます。

## 🚀 今すぐ使う

https://t0rry.github.io/Gen_MultiAnglePDF/

ブラウザから直接使用できます。インストール不要です。

## 機能

- ✨ ドラッグ&ドロップで画像を選択
- 🎨 複数のレイアウトに対応（2枚、4枚、8枚）
- 📄 PDF / PNG 形式で出力
- 🏷️ タイトルと日付をオプション追加
- 📐 16:9 アスペクト比で自動生成
- 🎯 リアルタイムプレビュー
- 🔒 データはブラウザ内のみで処理（サーバーに送信されません）

## 必要要件

- モダンなWebブラウザ（Chrome、Firefox、Safari、Edgeなど）
- インターネット接続

## 使い方

1. [アプリケーション](https://t0rry.github.io/Gen_MultiAnglePDF/)を開く
2. 画像を選択（2枚、4枚、8枚のいずれか）
3. レイアウトを選択
4. タイトルと日付を入力（オプション）
5. 出力形式を選択（PDF / PNG）
6. ダウンロードボタンをクリック
